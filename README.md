# Fake News Detection System

A machine learning-based web application designed to classify news articles as real or fake using Natural Language Processing (NLP) techniques.

## Project Overview

This project was developed as part of a university computing project to explore misinformation detection using machine learning techniques.

The system consists of:

- Frontend developed using React
- Backend API developed using FastAPI
- Machine Learning model built with Scikit-Learn
- Text preprocessing and feature extraction using TF-IDF

## Technologies Used

- Python
- Scikit-Learn
- FastAPI
- React
- HTML/CSS
- JavaScript
